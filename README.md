## 🚀 Featured Projects

### NOVA — Governance Platform for AI Agents *(2026)*
Run AI agents in a business under policy, with human approval and a verifiable audit trail.

`Python` `React 19` `TypeScript` `Tailwind 4` `SQLite` `Docker` `Terraform` `AWS` `Bedrock`

- Multi-tenant control plane over the open-source Hermes Agent runtime, without forking it.
- Agent permissions compiled into a fail-closed pre-tool-call hook, so a denied action is blocked inside the agent process, not just hidden in the UI.
- Write-ahead audit log: intent before every change, committed or failed after, with the human actor, tenant and correlation ID.
- Tenant isolation enforced in SQL, with fair scheduling and per-tenant concurrency limits.
- Human approval gates, governed scheduled automations, and agent routing across Telegram, Slack, Discord, WhatsApp and Signal.
- White-label Control Center (React 19, Tailwind 4) with RBAC, CSRF protection and strict CSP.
- Terraform for AWS (EC2, EBS, KMS, IAM, ECR, CloudWatch, SSM) with no inbound ports, IMDSv2 and per-integration IAM roles.
- 900+ automated tests, including tests that fail the build if architecture boundaries are crossed.

### DataEngine — AI Data-Operations Copilot *(2026)*
For accounting firms and retailers: messy spreadsheets in, approved fixes and client-ready reports out.

`Next.js 16` `React 19` `TypeScript` `Supabase` `PostgreSQL` `Python` `Polars` `DuckDB` `Docker` `GitHub Actions`

- AI profiles client workbooks and proposes materiality-ranked fixes; an accountant approves each change before it becomes a new immutable version.
- Queue-based agent architecture: Postgres job queue with leases, so the agent host needs no inbound ports and a restart delays work instead of losing it.
- Deterministic maths in Polars and DuckDB; the LLM only makes judgment calls, through a redaction layer that keeps raw customer rows away from the model.
- Secured multi-tenant Supabase backend: Row-Level Security, membership-checking database functions, tenant-scoped storage and Vault-held credentials.
- QuickBooks Online, Odoo and spreadsheet connectors; profit reports in English and Somali as PDF, Word, Excel and Markdown.
- CI/CD with GitHub Actions: Docker builds deploying over a private Tailscale network; 600+ Python tests plus an end-to-end suite.
